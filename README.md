# SHER — Smart Hazard Evaluation & Response

**See the Threat. Stay Ahead.**

SHER is a Java-based cybersecurity web application designed to analyze URLs, identify suspicious characteristics, evaluate potential phishing risks, and provide understandable security recommendations.

## Project Objectives

- Analyze URLs for suspicious characteristics.
- Identify potentially dangerous URL patterns.
- Generate explainable risk scores.
- Maintain user-specific scan history.
- Visualize security analytics.
- Integrate external threat intelligence services.
- Generate downloadable scan reports.

## Technology Stack

- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- Thymeleaf
- HTML, CSS and JavaScript
- PostgreSQL
- Maven
- JUnit 5

## Security Notice

SHER provides heuristic URL analysis and optional threat-intelligence checks. Its results are informational and do not guarantee that a website is safe or malicious.
